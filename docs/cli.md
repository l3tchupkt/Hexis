# CLI Reference

The CLI allows you to execute operations headlessly:
- `hexis detect`: Detect the chip.
- `hexis read firmware.bin`: Dump flash to disk.
- `hexis write firmware.bin`: Write firmware.
- `hexis erase`: Erase the chip.
- `hexis verify`: Verify flash contents against a file.
- `hexis backup`: Backup the current firmware into a `.hexis` project.
